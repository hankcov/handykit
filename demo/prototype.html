ptoolbox · 交互原型

单文件 HTML，双击即可在浏览器打开。样式按手机端 390×844 设计，四个模块的安全边界分开处理。

可以点的地方

  • 底部四个 tab 切换模块
  • 密码库：主密码解锁，或点「使用指纹解锁」
  • 指纹弹层里点指纹图标成功，「模拟失败」看失败态
  • 详情里切换密码 / 笔记内容显示与复制
  • 安全笔记与密码库共用解锁态：上锁后进不去
  • 油耗页右下「记一笔」弹出录入层
  • 体脂页历史记录进二级详情
  • AI：输入文字，模拟流式回复
  • 点头部的会话标题 → 会话列表，可切换 / 新建
  • 点「角色：xxx」→ 角色库，4 个角色可切换
  • 点闪电图标 → API 配置，切到「自定义请求」看请求头 / 请求体
  • 请求头可增删行；请求体模板支持 {{INPUT}} 等变量

操作手机：调研结论

  • 系统级（Gemini Intelligence）2026 已支持跨 App 多步操作，但国内 Gemini 服务缺位，用不上
  • 第三方可行路径：无障碍服务读 UI 树 + 截图 OCR，模拟点击滑动，无需 root（Andclaw / Pinky 类）
  • 硬伤：微信/支付宝/银行 App 会触发风控强制登出；无障碍权限面太重
  • 所以二期必须独立开关、默认关闭、金融与密码类 App 硬屏蔽

这版定了什么

  • 一期问答不读屏幕、不碰其他 App
  • API Key 存 Keystore，与密码库同一加密边界
  • 角色 = 系统提示词 + 默认参数；会话独立绑定角色
  • 5 种协议模板；自定义头 / 体按服务商分别保存
  • 指纹只做本机验证，不替代主密码
  • 安全笔记替掉 TOTP，共用同一把密钥
  • 油耗沿用满箱法指标与趋势
  • 体脂沿用 8 项指标与成员切换
还没定配色、圆角、图标是这一版的视觉提案。密码学方案、数据迁移、功能取舍都还没拍板——原型只解决「长什么样」。
