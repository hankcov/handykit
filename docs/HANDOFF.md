## 用户已明确的产品方向

- 个人自用 Android 手机工具箱，无应用账号、无云同步，本地优先；用户主动使用 AI、B 站或未来新闻时允许对应联网。
- 模块为首页、音乐、新闻、AI，以及油耗、体脂、独立加密安全笔记入口。
- 底部导航默认是首页、音乐、新闻、AI，四项可调整顺序并在本机保存。
- 密码管理器已移除，不恢复密码库入口、条目或导入；安全笔记保留，独立加密和解锁，不与 AI 凭据共用密钥。
- 笔记安全优先，不能因便利或进度降低加密、认证、锁定及备份恢复要求。
- 音乐支持本地添加和 B 站链接添加，添加入口收进右上角更多菜单；需要后台播放、歌单及歌词。
- AI 需要可创建、配置和选择的多角色，支持多会话及图片、PDF、TXT、Markdown 附件问答。
- 不做 AI 操作手机，不为此加入无障碍、截图捕获或悬浮窗权限及执行服务。
- 新闻先看示例样式，来源与实际功能后续讨论；RSS/RSSHub 是技术建议，尚不是用户拍板的接入范围。

用户此前拒绝了一批额外功能建议，包括密码生成器、密码修改历史、备份提醒、收藏、密码健康检查、会话内搜索与导出、油耗月报、体重目标等。不要因为技术选型方便就重新加入。需求中已有的会话列表搜索、手动备份恢复、首页导航排序仍保留，两者不要混淆。

## 当前原型能做什么

用浏览器直接打开 demo/index.html，无需安装依赖或启动服务。桌面上为手机外框，窄屏上全屏显示；原型是 HTML/CSS/原生 JavaScript，不是 WebView 打包方案。

| 页面 | 已具备的演示交互 | 限制 |
|---|---|---|
| 首页与导航 | 模块切换、安全笔记卡片入口；右上角排序或长按底部导航调整顺序 | 只有导航顺序尝试写 localStorage；浏览器不允许时仅本次有效 |
| 安全笔记 | 锁定与预览样式、显示虚构笔记、离开或页面隐藏时重新锁定 | 没有笔记主口令验证、加密或真正防截屏，不能放真实敏感笔记 |
| AI | 选择图片/PDF/文本文件、移除附件、模拟发送与回复；角色选择、新建、配置、删除；新会话继承快照 | 不上传、不读取附件正文、不调用模型；配置仅内存；未完成真实多会话持久化 |
| 音乐 | 原创视觉封面、播放样式、本地音频选择与浏览器试听、来源筛选、模拟 B 站缓存 | 本地使用 object URL，刷新后不保留；示例曲目没有音频；B 站未下载 |
| 歌单 | 示例、新建、选曲、移除、删除、播放第一首 | 内存演示；尚无重命名、拖动排序和完整歌单队列播放 |
| 歌词 | 原创示例、滚动预览、LRC/TXT 导入、实际音频的时间高亮与歌词定位 | 未联网搜词；复杂 LRC 与资源边界仍需正式实现；导入和关联只在内存 |
| 新闻 | 分类、头条卡片、列表、文章弹窗 | 全部虚构样例，无订阅或真实采集 |
| 油耗、体脂 | 虚构统计、记录和趋势样式 | 未录入真实数据、未算真实油耗、未连接 BLE |

示例文字在 UI 中已明确标注，不应在接入前删除这些标注制造“可用”的错觉。正式实现完成一个能力并通过验证后，再替换对应演示状态。

## 已执行的验证

原型使用 Node --check 检查脚本语法，使用 Python HTMLParser 检查静态 ID 唯一性、脚本中的直接 DOM 引用与弹窗关闭目标。总体设计的本地链接、UTF-8 与代码块结构已检查。

这些是静态检查，不是完整测试。没有浏览器截图验收、Android 构建、真机操作、音频格式矩阵、BLE 实测、笔记安全评审、B 站下载成功率或新闻源联调结果。下一位开发者不能据此声称“测试全部通过”。

### 必须保留的安全说明

单 APK 下普通 Gradle 模块、数据库分离或同 UID 的另一个进程，都不能等同于操作系统强制禁止安全区联网。当前方案是可审计的逻辑隔离；如果用户要求系统级离线，需重新设计无网络权限的独立安全应用。

AI 凭据的自动使用与“每次解密都强制身份认证”也有取舍：若 App 能自动取得密钥发请求，仅在查看按钮前认证不能抵御同 UID 恶意代码。总体设计已解释，不允许把两者同时宣传为无条件保证。

安全区使用虚构数据开发与验证。发布前必须完成 K1—K10，不以 HTML 页面遮挡、笔记主口令哈希存在或某个加密库已引入作为笔记安全验收依据。

### 油耗项目

路径：D:/code/github/carassistant/android。

可复用候选为 FuelMath、部分 MetricsCalculator、CSV 编解码与相应测试向量。关键源码链接见总体设计末节。

已发现的迁入差异：

1. AppDatabase 启用 fallbackToDestructiveMigration，不能进入新工程。
2. 累计行驶距离为最大里程减最小里程，与当前要求的有效区间累计不同。
3. 续航按油箱容量或上次加油量估算，不能直接当作当前剩余续航。
4. CSV 以同车、日期、里程判重复，需要补充完全重复与字段冲突的区分。
5. release 使用 debug 签名，新工程必须建立独立持久签名流程。

### 体脂项目

路径：D:/code/github/smart-body-scale-android。

可复用候选为 BLE 协议解析、测量会话归并、成员与测量 JSON 字段、算法测试向量。

已发现的迁入差异：

1. 无阻抗的部分指标使用 0 表示不可用，需映射成空值与原因。
2. 未确认成员时存在用首个成员身高或默认 170 cm 计算 BMI 的路径，不能直接沿用。
3. 原数据没有新需求要求的完整输入快照与来源信息；旧数据只能标记 LEGACY/UNKNOWN，不能伪造。
4. 当前检查的实体没有基础代谢字段；不为凑齐指标临时补一个无验证公式。
5. WebDavManager 已有 version=1 成员/测量 JSON 备份结构，可研究补本地导出；不等同于已验证的本地导出功能。
6. 原项目含 WebDAV、Health Connect 相关代码和权限，不在新需求内的能力不迁入。

新旧包名不同，不能直接读旧应用私有数据库。若有必须保留的数据，先建立导出、样本核对、全量迁移和回退路径，再切换使用。

## 仍需用户或实机信息

- 目标手机型号与 Android 版本，是否必须兼容旧设备。
- AI 实际服务商、模型及安全提供测试凭据的方式。
- B 站可用于验证的普通内容样本；一期仍按无需登录设计。
- 体脂秤型号、是否存在必须迁移的历史数据。
- 新闻来源、RSSHub 是否接受依赖实例、是否需要正文离线阅读与自动刷新。
- 若涉及密码保护强度升级，单 APK 逻辑隔离是否满足，或需要独立安全应用。

## 不应误判为完成的项目

- Demo 的 B 站进度是定时器，不是下载任务。
- Demo 的 AI 回复是固定示例，不是模型响应；角色编辑不代表完整 Provider 参数生效。
- Demo 的本地音频 object URL、歌词与歌单仅本次内存存在，不是持久保存。
- 歌单“播放第一首”不是正式的整单连续播放实现。
- 新闻样式中的分类、来源与标题不代表已选定真实资讯渠道。
- 源码存在 BLE UUID 或体成分公式，不代表支持所有秤或指标有医学验证。
- 使用成熟加密库仍需要完整密钥、生命周期、备份和发布安全设计。
