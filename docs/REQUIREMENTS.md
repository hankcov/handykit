# ptoolbox · 需求

个人自用的手机工具箱。无应用账号、无云同步，业务数据默认仅保存在本机；AI 请求按用户操作发送至所配置的服务商。

模块：AI、油耗、体脂秤、独立加密安全笔记、新闻、音乐播放器。安全笔记属于独立加密数据域，其余为普通数据区；API Key 和鉴权请求头按敏感凭据单独保护。

本文为优化后的需求基线。原有编号保留，新增需求继续编号；“后续”不计入一期验收，“待确认”需在对应功能实施前解决。

## 一期范围

| 范围 | 内容 |
|---|---|
| 一期必做 | 本地数据管理；独立加密安全笔记；加密备份恢复；AI 固定协议图文及 PDF、文本附件问答；油耗记录与统计；已支持体脂秤的连接、测量、成员和历史记录 |
| 后续 | AI 自定义请求体、响应提取与更多协议；油价、气温、加油站定位 |
| 当前不做 | AI 操作手机：不读取屏幕、不模拟点击、滑动或输入，不跨 App 执行任务；不为此申请无障碍、屏幕捕获或悬浮窗权限 |
| 新增模块 | 音乐播放器纳入开发范围，核心为 B 站链接添加、音频缓存与离线播放；新闻保留模块，内容来源、功能与排期后续讨论，不作为当前一期交付承诺 |
| 切换前置条件 | 若原项目存在必须保留的数据，先验证迁移结果，再切换使用；不得以替换应用为由丢弃旧数据 |

迁入模块先核对原代码、算法、数据格式和设备支持范围。本文未核实原项目实现，不能将原有计划视为已实现能力。

## 全局

| 编号 | 需求 |
|---|---|
| G1 | 无应用账号、无注册和账号登录；安全笔记采用独立本地主口令解锁。本地记录、查询、统计和备份恢复离线可用，AI 远程问答需要联网 |
| G2 | 业务数据默认仅本地保存；无统计、埋点、崩溃上报。AI 仅发送用户提交的文字、主动选择的附件及其必要解析结果、会话提示词和明确纳入的历史上下文，不自动读取其他模块、剪贴板或其他 App；附件详情与授权见 M1—M12 |
| G3 | 联网功能可关闭；关闭后不发起对应请求，联网失败不阻断本地功能。首次发送 AI 请求前说明接收服务商与发送内容范围 |
| G4 | 数据导出必须由用户显式操作；安全笔记加密区与敏感凭据只能加密导出。系统备份、设备迁移和临时文件也不得绕过此规则 |
| G5 | 安全笔记独立解锁；普通模块不得读取笔记内容。API Key 的访问规则见 A10 |
| G6 | 从应用首页进入常用模块入口不超过两次点击；解锁、系统权限和数据录入不计入入口点击数 |
| G7 | 保存失败明确提示，不显示成功；删除和覆盖已有数据前明确影响范围并确认 |
| G8 | 数据结构有版本；升级失败不得清空原数据。支持的 Android 版本、设备及数据量基线见待确认项 |
| G9 | 底部导航仅包含首页、音乐、新闻、AI，默认按此顺序排列；支持调整四个入口顺序并在本机保存，不因重启恢复默认。首页提供导航排序入口，长按底部导航也可进入排序 |

## 独立加密安全笔记

密码管理器已移出范围：不管理站点、账号、密码条目，不提供密码库入口或第三方密码库导入。原 P1—P12、G10、D9 停用，不复用；V2—V4 改为独立安全笔记验收。安全笔记独立保留，不是通用密码管理器。

| 编号 | 需求 |
|---|---|
| N1 | 本地保存敏感文本，字段为标题、正文、分类、创建及更新时间；支持增删查改和搜索，不提供站点/账号/密码专用字段 |
| N2 | 使用独立加密数据库与笔记主口令；首次设置并确认，主口令不上传、不明文保存。AI、音乐和新闻无笔记读取接口 |
| N3 | 标题、正文、分类、索引、数据库日志和临时数据全部纳入加密；分类可自定义 |
| N4 | 正文默认隐藏，解锁后可显示和显式复制；剪贴板默认 30 秒后尝试清理，只清理仍属于本次复制的内容，说明系统时序限制 |
| N5 | 手动锁定、熄屏、切后台、离开笔记立即锁定；前台闲置默认 5 分钟锁定，范围待验证。锁定遮蔽列表、搜索、正文和编辑，进程重建默认锁定 |
| N6 | 可在验证笔记主口令后启用系统生物识别；认证必须控制密钥使用，登记变化或密钥失效回退主口令，不重建或删除原库 |
| N7 | 修改主口令先验证原口令，失败原数据仍可读；成功撤销旧会话与生物识别授权。遗忘无账号找回，只能凭有效加密备份及其口令恢复，或确认清除笔记后重建 |
| N8 | 敏感页面防截屏、隐藏任务预览；不记录正文、口令或密钥。安全字段不进入页面状态快照；强制锁定优先于保存未完成编辑 |
| N9 | 独立加密备份恢复；不与 AI 凭据共用密钥。错误口令、损坏或中断时保留原数据，不自动清库 |

### 安全笔记发布门槛

以下 K 编号保留用于安全笔记，取代旧密码库门槛的适用对象。

| 编号 | 需求 |
|---|---|
| K1 | 使用受维护的成熟加密实现，认证失败拒绝解密，不降级明文或弱算法 |
| K2 | 笔记主口令采用专用口令派生算法与随机盐；实测资源成本，参数版本化，不静默减弱 |
| K3 | 随机数据密钥独立于笔记主口令、备份口令和 AI 凭据；所有封装副本保护，nonce 不复用 |
| K4 | 生物识别由系统认证约束密钥实际使用，不只切换界面布尔值 |
| K5 | 标题、正文、分类、索引、WAL、缓存及状态保存不泄露明文 |
| K6 | 数据访问层检查有效笔记会话，锁定后的迟到结果不得显示；笔记模块无网络依赖，不向其他模块提供正文接口 |
| K7 | 主口令支持长口令，不静默截断或规范化；改口令后撤销旧授权，说明历史备份不会自动失效 |
| K8 | 导出前重新验证笔记主口令；备份认证加密和资源边界校验通过，不输出部分明文 |
| K9 | 正式包无测试解锁、调试转储或任意证书信任；组件和系统备份不得绕过保护 |
| K10 | 发布前验证明文扫描、篡改、错误口令、锁定竞态、重建、生物识别、日志和跨设备恢复；泄露、绕过与丢失问题阻断发布 |

同一 APK 内属于逻辑隔离，不承诺操作系统强制断网。笔记若包含敏感文字，用户手工粘贴到 AI 后仍会发送给服务商。

## 备份与恢复

备份由用户手动发起，一期以“按数据域覆盖恢复”为基线，不做隐式合并。

| 编号 | 需求 |
|---|---|
| B1 | 提供安全笔记、AI、油耗、体脂四类备份；界面列明包含与排除项，安全笔记独立导出与恢复 |
| B9 | 音乐模块提供独立备份，包含曲目来源、分 P 标识、播放列表和进度；音频缓存默认排除，导出前明确说明，可显式选择纳入加密备份。未恢复缓存的条目标记需重新缓存，不保证来源失效后可重新获取；新闻备份范围随其功能定义后再确定 |
| B2 | 所有备份包均以用户设置并确认的备份口令加密，包含格式版本及完整性校验；备份口令可与笔记主口令不同，不保存可用于找回它的明文副本 |
| B3 | 安全笔记加密区备份仅在解锁后生成；在新设备凭备份口令可恢复，并设置本机笔记主口令，不依赖旧设备密钥或生物识别 |
| B4 | AI 备份包含会话、角色、服务商及模型配置；默认包含本地保存的会话附件、解析文本及关联，导出前展示预计体积，可显式排除附件。默认排除 API Key 和敏感请求头，用户显式勾选后才纳入加密包；未恢复凭据的配置标记为待补充，未包含的附件标记为缺失，不伪装为可重发 |
| B5 | 油耗备份包含车辆和加油记录；体脂备份包含成员、原始测量、指标来源及算法版本。CSV 为单独的数据交换功能，不替代完整备份 |
| B6 | 恢复前完整校验口令、文件完整性、格式版本和数据关联，展示数据域、记录数与覆盖范围；确认后原子替换所选数据域，其他数据域保持原样 |
| B7 | 口令错误、文件损坏、不支持的版本、空间不足或恢复中断时，不留下部分恢复状态，不破坏原数据；禁止先清空再验证 |
| B8 | 导出完成后反馈文件位置和结果；失败不显示成功。用新安装环境执行恢复演练，核对条目、关联、凭据排除状态和统计结果 |

## AI

AI 支持文字、图片与文档附件问答：用户输入文字或主动选择附件 → 本地校验及必要解析 → 调用用户配置的 API → 返回文本。一期支持图片、PDF、TXT 和 Markdown 输入，暂不包含语音、视频、图片生成与办公文档格式。当前不包含操作手机能力，不预留对应执行服务或权限入口；未来如需加入，另行评估需求与安全边界。

| 编号 | 需求 |
|---|---|
| A1 | 支持多角色：系统提示词与默认参数，可创建、编辑、删除 |
| A2 | 支持多会话：新建、切换、搜索、删除；每个会话独立绑定角色快照、服务商与模型 |
| A3 | 新会话继承当前角色快照；修改或删除角色不改变已有会话。主动更换会话角色或模型仅影响后续请求，保留已有消息 |
| A4 | 一期先完成一种固定协议的完整问答体验，具体协议与实际服务商见待确认项；OpenAI 兼容、Anthropic Messages、Gemini 作为候选，不等同于一期全部支持 |
| A5 | 每个服务商可配置 Base URL、模型名、API Key；明确展示目标服务商。鉴权凭据只发往配置目标，不随跨来源重定向转发 |
| A6 | 支持增删自定义请求头，入口默认收进高级选项；鉴权值按敏感凭据处理，不在配置预览或错误信息中泄露 |
| A7 | 后续：自定义请求体模板，可引用输入、提示词、模型名和密钥；变量须按目标结构正确转义，不允许执行任意代码 |
| A8 | 后续：配置响应正文提取路径；非流式与流式格式分别定义，不能假设同一提取路径适用于所有协议 |
| A9 | 配置按服务商分别保存，切换不串配置。删除服务商前提示影响；关联会话保留可读，继续发送前须重新绑定有效配置 |
| A10 | API Key 和敏感请求头采用独立的设备保护凭据存储，不与安全笔记解锁绑定；AI 模块只能读取自身凭据。界面默认遮罩，禁止明文导出和日志记录，查看明文或纳入备份前做本机身份验证；无可用身份验证方式时仅允许替换，不允许显示或导出已有值 |
| A11 | 发送前校验协议必填项、URL 与请求结构；错误不发出请求且指出可修正字段。后续模板渲染后仍须验证 |
| A12 | 支持流式输出、停止生成、超时和失败反馈；不阻断其他功能。停止或失败后保留部分回复并标记状态，不自动重试；手动重试生成独立回复，不重复插入用户消息 |
| A19 | 每次请求只纳入当前会话提示词与选定历史，不跨会话取数；支持不携带历史。发送前可查看上下文范围；超出所配预算时提示裁剪并确认，不静默删除消息或混入其他数据 |
| A20 | 聊天记录保存在本机普通数据区，用户可删除；提示远程服务商的数据处理规则由其决定，本机删除不代表远程副本已删除 |
| A21 | 安全笔记加密区内容不会自动加入问答；用户手工输入或粘贴的敏感文字会随请求发送，首次使用时说明此边界 |
| A22 | 输入支持多行与会话独立草稿；文字为空且无有效附件时不可发送，仅附件提问允许发送并记录明确的默认指令。创建本地消息并进入发送流程后清空输入，校验失败则保留原文与附件；发送失败仍保留可重试的消息。同一会话生成中禁止重复发送，用户可先停止再提交下一条 |
| A23 | 每条回复记录服务商、模型、生成时间及完成状态；区分等待响应、生成中、完成、用户停止、失败与应用中断，不将空回复标为完成 |
| A24 | 明确区分鉴权失败、模型不可用、限流、网络断开、连接超时及响应格式不支持，提供针对性处理提示；不将请求头、密钥或原始敏感响应直接展示为错误信息 |
| A25 | 用户切换会话后，回复仍归属原会话，不串写当前界面；切换不自动取消请求。进入后台可继续多久取决于实际运行能力，不承诺常驻；进程终止后未完成回复标记为中断，不自动重发 |
| A26 | 角色参数作为新会话默认值，会话可单独覆盖；界面展示本次实际使用的服务商、模型、提示词与参数。未配置参数采用协议默认行为，不伪造统一默认值；不支持的参数发送前提示 |
| A27 | 上下文只纳入用户选定的消息及明确选择的回复版本；失败提示不作为模型回复发送，中断的部分回复默认不纳入。清除上下文仅改变后续请求范围，不删除本地消息；界面明确区分清除上下文与删除会话 |
| A28 | 请求只允许通过 HTTPS 发送到远程服务商并验证证书，正式包不得提供忽略证书错误的开关；Base URL 或鉴权配置修改后必须重新校验目标，错误时不发送凭据 |

### AI 完善范围

一期补齐上述基础行为，并支持下节定义的图片与文档问答。选定的首个协议与模型组合必须通过图文、PDF 和文本附件的端到端验收；仅支持文字不算完成一期 AI 范围。

以下方向待用户确定后再纳入正式需求：编辑提问与重新生成的分支规则、Markdown 与代码显示、多模型配置与切换体验、自定义请求能力的提前实现。暂不加入此前已否决的会话内搜索和会话导出；A2 中的搜索仅指现有会话列表搜索。

原编号 A13—A18（操作手机）已移出当前需求，编号保留不复用。

### 图片与文档附件

附件由用户主动选择，选择和本地处理本身不触发上传。模型原生接收文件与本地解析后发送内容是两种不同路径，必须在发送前展示实际路径，不把本地解析称为模型已读取原文件。

| 编号 | 需求 |
|---|---|
| M1 | 支持系统选择器选取图片或文件，图片支持 JPEG、PNG、WebP，文档支持 PDF、UTF-8 TXT、Markdown；可多附件与文字混合发送。扩展名与实际格式不符、格式不支持时明确拒绝；不申请整库扫描权限，不自动上传相册或目录 |
| M2 | 发送前展示图片缩略图、文档名、类型、大小、PDF 页数及处理状态，支持预览和移除；附件未就绪或解析失败时阻止发送并定位问题，不能静默忽略附件后仅发送文字 |
| M3 | 模型配置记录图片、原生 PDF、文件上传等能力与相应限制，区分已验证、用户配置和未知；不能只根据模型名称猜测。切换模型后重新检查附件及历史兼容性，不支持时提示换模型或选用可用的解析路径 |
| M4 | 图片默认本地去除定位等非必要元数据；压缩、缩放时展示处理结果并允许预览，不静默裁掉文字。图片作为图像输入发送给支持的模型，不仅凭文件名声称已理解图片 |
| M5 | PDF 可采用已验证的原生文件输入，或本地提取带页码的文本；展示实际使用方式和发送页范围。存在图片、表格或复杂布局时提示文本提取可能遗漏信息；不把纯文本提取当作完整视觉理解 |
| M6 | 扫描 PDF 或无可提取文本的页面不得作为空白文档发送；可使用已支持的原生 PDF 或选定页面渲染为图片的路径，否则明确提示当前不支持。OCR 作为后续可选能力，未经实现不宣称可用 |
| M7 | TXT 和 Markdown 本地解码并展示预览；编码不支持时提示转换，不静默以乱码继续。附件内容作为用户提供的资料，不作为系统指令执行；不执行宏、脚本、嵌入内容，也不自动访问文档链接或加载外部资源 |
| M8 | 定义并在发送前校验单文件大小、附件数量、PDF 页数、图像尺寸、解析耗时和请求上下文预算；参数见 D10。超限时让用户选择文件、页范围或取消，不静默截断；一期不承诺任意长度文档的全文理解，不自动总结后冒充全文 |
| M9 | 首次附件发送说明接收服务商、原文件或解析内容的发送范围；每次发送前可查看本次附件与历史附件范围。不得从安全笔记加密区提供直接选取入口，未点击发送前不做远程预上传；文件上传阶段也须归属该次用户授权 |
| M10 | 会话附件保存为应用私有副本，避免原文件移动后无法继续；复制失败保留草稿并提示。附件、缩略图与解析缓存仅供所属会话使用，删除会话时清理无其他引用的副本；不修改用户原文件，不向系统相册公开附件缓存 |
| M11 | PDF 回答提示模型按文件名与页码提供依据，文本按文件名与可定位段落提供依据；可打开本地原文核对。模型引用仅为待核对依据，不宣称必然正确；无法校验的引用标记未验证，不生成虚假可点击定位 |
| M12 | 后续请求是否重传历史附件遵循明确的上下文选择；附件缺失、远程文件过期或模型不兼容时先提示，不悄悄省略。使用服务商文件上传 API 时记录上传状态与远端引用，失败不无限重复上传；支持删除接口时请求删除并报告结果，不将删除本地副本等同于远端已删除 |

附件内容仍属于 AI 普通数据区，不具有安全笔记的同等保护承诺。选择敏感文件前明确提示；用户主动提供的文件和解析内容可能由所选服务商处理与留存。

## 油耗助手

从 carassistant 合入，先核实原有算法、异常判据和数据格式。若与下列口径不一致，迁入前记录差异并确认，不静默改变历史含义。

| 编号 | 需求 |
|---|---|
| F1 | 按满箱法计算：同车两个有效满箱记录之间，以后续各次加油升数之和除以里程差再乘 100，单位 L/100 km；不含起始满箱的加油量。首条及未形成完整区间的记录不生成区间油耗 |
| F2 | 支持多车，所有里程与油耗先按车分组；默认单位 km、L、元，其他单位后续扩展 |
| F3 | 录入车辆、时间、里程、满箱状态及金额/升数/单价。三项价格字段输入两项推算第三项；三项均手填且不一致时提示修正。默认车辆和单价可复用，上次单价显示来源日期；快捷录入目标的具体计步口径待确认 |
| F4 | 必填缺失、非正升数、非法金额等禁止保存；重复记录、里程回退或超阈值油耗提示后可显式保留为异常记录。受影响区间不参与油耗和续航估算，但已发生的合法费用仍计入累计油费，并显示异常数量 |
| F5 | 首页按所选车辆展示最新有效完整区间油耗、有效区间累计行驶距离、全部有效费用总额。续航与预计加油里程仅在有可验证的剩余油量依据时展示估算及依据，否则显示不可用，不假设掌握实时油量 |
| F6 | 展示油耗趋势；缺失与异常区间显示断点和原因，不显示 0 或 NaN，不跨异常区间拼接计算 |
| F7 | 历史记录可查看、编辑、删除；变更后重算受影响区间及汇总，保留各车隔离 |
| F8 | CSV 导入导出列明字段、单位、编码与版本；按车牌归车，导入预览新增、重复及错误记录，确认后原子提交。完全相同的记录跳过，有冲突的候选不自动覆盖；失败保留现有数据 |
| F9 | 后续：油价同步与气温信息，本地缓存优先，说明更新时间；无网与失败不阻断记账 |
| F10 | 后续：加油站定位，按需申请粗略位置，仅取一次，不后台跟踪 |
| F11 | 支持标记漏记导致的无效区间；从下一有效满箱记录重新建立计算基线，不将漏记造成的偏差当作正常油耗 |

计算验收样例：同车在 1000 km 加满，1200 km 加 10 L 未满，1500 km 加 20 L 至满，则完整区间为 500 km、30 L、6.0 L/100 km；起始记录的加油量不计入。编辑中间记录或终点里程后重新计算；不同车辆不得串算。

| S8 | 若有需保留的旧数据，迁移为切换前置条件：先提取样本核对成员、时间、单位、条数和指标，再全量迁移；不具备迁移条件时保留旧应用与原数据 |
| S9 | 历史记录保存本次算法输入；成员资料后续修改不静默改写历史。重新计算须显式操作并保留原始测量及算法版本 |

## 音乐播放器

核心流程：用户粘贴或通过系统分享发送 B 站视频链接 → 解析标题、作者及分 P 信息 → 确认目标音频 → 缓存至本机 → 离线播放。缓存针对用户有权保存的内容，不承诺任意链接均可获取；具体接入方式须先通过真实样本验证，不将链接解析结果视为缓存成功。

| 编号 | 需求 |
|---|---|
| U1 | 支持手动粘贴 B 站视频链接、接收系统文本分享，识别分享文本中的视频地址；支持标准视频链接与 b23.tv 短链接。不自动读取剪贴板，识别到多个链接时让用户选择 |
| U2 | 解析后展示原视频标题、作者、封面、时长与原始链接；多分 P 视频先列出分 P 并选择，不默认将所有分 P 下载。非视频链接、直播和暂不支持的内容明确提示 |
| U3 | 用户确认后创建音频缓存任务，优先获取可用的独立音频轨；不为音频播放默认下载完整视频。不默认转码为 MP3，采用播放器支持的原音频格式；无可用音频轨或编码不支持时明确提示 |
| U4 | 缓存任务显示排队、解析、下载、校验、完成、失败与取消状态及已下载大小；已知总大小时显示进度。支持取消和手动重试；只有完整下载并验证可播放后才加入可离线播放列表，残缺文件不标记成功 |
| U5 | 处理音频地址过期、网络中断、空间不足与来源失效；有条件时重新解析地址并续传，无法验证是同一资源时重新下载，避免拼接错误。重试次数有限，失败不无限请求，不破坏已有完整缓存 |
| U6 | 支持播放、暂停、拖动进度、上一首、下一首、顺序播放、单曲循环和随机播放；显示标题、作者、时长与进度，记住本地播放位置。离线时直接读取已完成缓存，不依赖重新解析链接 |
| U7 | 支持后台与熄屏播放、媒体通知及耳机控制；使用系统要求的媒体播放服务，处理音频焦点、来电和耳机断开，默认拔出耳机暂停。进程终止后保留播放位置，不擅自重新开始播放 |
| U8 | 支持曲目列表、播放队列和手动播放列表；以视频与分 P 标识去重，同一目标重复添加时复用已有曲目或任务，不重复占用空间 |
| U9 | 显示总缓存占用、单曲占用并支持逐项或批量删除音频；删除前说明是否仅清缓存或连同曲目移除。用户主动缓存的完整音频不因普通临时缓存清理被静默删除 |
| U10 | 音频与封面保存在应用私有目录，不自动公开到相册或共享存储；仅在用户确认缓存时联网下载，移动网络下载前提示并支持仅 Wi-Fi。播放缓存不得读取安全笔记加密区或调用 AI，媒体元数据也不得混入敏感内容 |
| U11 | 一期不依赖 B 站登录；需要登录、付费、会员、地区权限或其他访问授权而无法获取时明确提示，不绕过限制。未来若确需登录须单独定义授权与凭据保护，不复用安全笔记主口令或正文 |
| U12 | 音频来源适配独立于播放器，平台接口变化只影响新解析或新缓存，不影响本机已完成文件的播放。接入方案、支持链接类型与错误样本必须先验证，解析服务若需上传链接或依赖第三方须明确说明并另行确认 |
| U13 | 支持通过系统文件选择器添加本地音频，与 B 站缓存统一进入曲库；标明来源，支持按全部、本地、B 站筛选。导入检查实际格式和可播放性，重复文件提示并避免重复占用；不扫描整机文件 |
| U14 | 音乐页以当前播放、播放控制及曲库为主；本地添加和 B 站添加统一收进右上角更多菜单，不使用大幅添加卡片或突出悬浮按钮。导入或缓存失败保留已有曲库和播放状态 |
| U15 | 支持新建、重命名与删除歌单，向歌单添加或移除本地及 B 站曲目；同一歌单内不重复添加。删除歌单不删除曲库音频，支持按歌单顺序播放；歌单内容纳入音乐元数据备份 |
| U16 | 提供当前曲目的歌词页，支持手动导入 UTF-8 LRC 与 TXT，并与曲目关联；LRC 按播放进度高亮，支持点击有时间戳的歌词定位播放，TXT 显示静态正文。无歌词显示空状态，不把视频字幕或其他曲目的歌词当作匹配结果 |
| U17 | 歌词与关联纳入音乐备份，歌词来源明确；自动网络匹配与第三方歌词服务暂不默认接入。HTML Demo 使用原创示例歌词并显式标注，与演示曲目不构成真实对应 |
