## 模块实现对照

### 油耗（carassistant 迁入）
- F1 满箱法：`FuelMath.segments` 按加满事件切区间、起始满箱油量不计、里程严格递增校验、异常返回 null 不返回 0。验收样例 1000/1200/1500km 得 6.0 L/100km，单测通过。
- F2 多车隔离：所有计算先按 vehicleId 收窄。
- F3 价格三字段输入两项推算第三项，三项冲突提示。
- F4 必填校验、重复/里程回退/超阈值（1–25 L/100km）提示后可显式保留异常。
- F5 续航：有油箱容积按油箱算，无则按上次加油量并标注依据；无依据显示不可用。
- F6 趋势 Canvas 自绘，异常区间留断点，不画 0/NaN。
- F7 编辑删除后重算。F11 可标记漏记无效区间并从下一满箱重建基线。
- F8 CSV 表头固定、按列名容错、手写 RFC4180 解析、事务内原子导入、同车同日期同里程去重。
- 未纳入一期（原需求即为后续）：油价同步、气温、加油站定位（F9/F10）。

### 体脂秤（smart-body-scale-android 迁入）
- S1 扫描/连接/测量/断开状态与取消；20s 扫描超时、最多 3 次重连、离开模块 `close()` 后无后台重连。
- S2 逐项标注来源；**不提供无阻抗估算**，无阻抗时 BIA 指标显示「不可用」而非 0。单测覆盖有/无阻抗两条路径。
- S3 八项指标 + 基础代谢；体成分标为参考值。
- S4 多成员：单成员自动绑定；多成员按体重 ±10kg 最近匹配，多候选/超阈值返回需用户确认，不静默绑定；支持事后纠正归属并重算。
- S5/S6 历史、详情（原始测量/来源/协议/算法版本）、按成员体重趋势；同 sessionId 重复广播只存一条。
- S7 权限：Android 12+ 申请 BLUETOOTH_SCAN/CONNECT，以下申请 ACCESS_FINE_LOCATION；拒绝后历史仍可用。
- S8 旧数据迁移：见「待确认」——无旧数据样本，未做迁移。
- 支持协议：AFU、蓝牙 SIG WSS/BCS、小米 1/2、Yolanda、OKOK/芯海、香山，含非秤厂商 companyId 黑名单。
- **必须真机验证**：BLE 实际扫描/握手/读数、各型号协议解析、生物识别以外的秤交互。协议解析有纯 JVM 实现但尚无设备样本回归。

### 安全笔记（独立加密数据域）
- N1/N3 标题、正文、分类均为 AES-256-GCM 密文落盘；搜索在内存解密后过滤，不建明文索引。
- N2 主口令经 PBKDF2WithHmacSHA256（210k 迭代、随机盐）派生 KEK，封装随机 DEK；DEK 与主口令、备份口令、AI 凭据独立。
- N4 正文默认隐藏，显式复制；剪贴板 30 秒后仅当内容仍属于本次复制才清理（记录 SHA-256 + 时间戳）。
- N5 手动锁定、ON_STOP 立即锁定、熄屏广播锁定、5 分钟闲置锁定；锁定后 `generation` 递增使旧 DEK 引用失效，迟到结果不显示。
- N6 生物识别：系统 `BiometricPrompt` + Keystore 中带用户认证约束（30s 有效、登记变化失效）的密钥解封 DEK。26/27 降级到 KeyguardManager 设备凭据。
- N7 改口令先验证旧口令，仅重封装同一 DEK；失败零改动。
- N8 `FLAG_SECURE` 防截屏；无正文/口令日志。
- **安全模型边界（如实说明）**：这是字段级加密 + Keystore 包裹，不是整库 SQLCipher。数据库表结构、行数、时间戳仍是明文；同一 APK 内属逻辑隔离，不承诺系统级强制断网。认证失败（GCM tag 校验）会拒绝解密并显示占位符，不输出乱码或半明文。
- **必须真机验证**：Keystore 认证约束密钥与 BiometricPrompt 的实际配合（不同 OEM 行为差异）、剪贴板清理时序、FLAG_SECURE 在任务切换的表现。

### AI
- A1/A2/A3 多角色（系统提示词+参数）、多会话（搜索/新建/删除/切换）、角色快照固化；改删角色不影响旧会话。
- A4 **一期固定 OpenAI 兼容协议**（DeepSeek/Kimi/自建兼容端点）；Anthropic/Gemini 明确拒绝，不伪装可用。
- A5/A9 每服务商独立配置 Base URL/模型/Key；强制 HTTPS，拒绝 http:// Base URL；凭据不随重定向转发。
- A6/A10 自定义请求头收进「高级选项」；API Key 与敏感头用 Keystore 独立密钥加密存 DataStore，与安全笔记解锁不绑定；明文查看需设备凭据验证，无机主验证只允许替换不允许显示；不写日志、不导出。
- A12 流式输出（SSE）、停止生成、超时与失败分类（鉴权/限流/模型/网络/超时/格式），停止/失败保留部分回复并标状态，不自动重试。
- A19/A22/A25/A27 上下文只取当前会话选定消息；草稿按会话保存；生成中禁重复发送；切换会话结果归属原会话；清除上下文只移游标不删消息。
- M1/M2 图片 JPEG/PNG/WebP 与 PDF/TXT/MD 主动选择；magic bytes 校验拒绝伪造扩展名；发送前展示附件；单文件 20MB/6 个/40 页/边长 4096 上限。
- M4 图片去 EXIF 定位并重编码。M5/M6 PDF 用 PdfRenderer 逐页渲染计数；**本地无法提取文本时不假称理解正文**，扫描页明确提示。M7 TXT/MD 严格 UTF-8。
- **必须真机/服务验证**：真实服务商的流式返回、图片型请求的模型兼容性、PDF 原生能力的实际边界。当前无真实 API Key，未做端到端请求验证。

### 音乐与备份
- U1/U2 B 站标准链接与 b23.tv 短链解析、公开 API 取标题/作者/封面/分 P；分 P 需用户选择。
- U3/U4 音频获取尝试 playurl 低清流（`fnval=0`），流式下载与状态机（排队→解析→下载→校验→完成/失败/取消）；完整校验后才标可播放，残缺不入列表；3 次有限重试。
- U6/U7 Media3 播放器、顺序/单曲/列表循环/随机、进度记忆、`MediaSessionService` 后台播放、耳机断开暂停。
- U8/U9/U13/U15 曲库去重（bvid+cid / contentHash）、本地音频导入、歌单管理、缓存占用与清理。
- U16/U17 LRC/TXT 歌词导入、按进度高亮、点击时间戳跳转。
- **诚实边界**：不引入 yt-dlp，不转码 MP3，不下载完整视频。B 站风控可能要求 wbi 签名/登录/大会员/地区权限；拿不到音频时返回明确失败原因，**不伪造成功**。低清流格式（flv/m4a 等）以原样缓存，部分封装 Media3 可能探测失败。这些是 U11/U12 的已知限制，需真实样本验证。
- B1–B9 五域加密备份（笔记/AI/油耗/体脂/音乐元数据）；备份口令独立派生、包内版本+域清单+记录数+SHA-256；**API Key 与敏感头始终排除**，音频缓存默认排除；恢复先校验口令/摘要/版本/关联再原子覆盖所选域，失败按快照回滚，其他域不动。

## 已知技术取舍

- 安全笔记采用字段级加密而非 SQLCipher 整库加密，规避 native 库编译与兼容风险；代价是表结构/行数/时间戳非密文。若后续要求系统级隔离，按技术设计拆为独立无网络权限的笔记 App。
- AGP 9 内置 Kotlin + KSP 需 `android.disallowKotlinSourceSets=false`（实验开关），见 ADR 0001。
- AppDatabase 与 NoteDatabase 是两个 Room 库，无法共用事务；跨库恢复失败按快照回滚，极端强杀场景仍可能部分写入。
